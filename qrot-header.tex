\begin{abstract}
  The Random Oracle Model (ROM) has been highly successful in bringing to life
  cryptographic schemes that are 1) efficient and 2) provably secure, with
  security proofs that are often furthermore 3) conceptually simple, and 4) tight. 
  However, a quantum attacker would be able to run the primitives we are
  modelling as random oracles (say, SHA3) in \emph{quantum superposition}. 
  Hence, if we want to claim post-quantum security relative to random oracles,
  we better ensure our random oracles are \emph{quantum-accessible}.

  This is the Quantum Random Oracle Model (QROM).
  Unlike its classical counterpart, security proofs in the QROM are often both
  1) conceptually challenging and 2) lossy. The issue boils in large part down to three main
  challenges, relating to the non-applicability of three simple yet
  powerful proof techniques that sit at the heart of the random oracle model:

  \begin{enumerate}
    \item Reprogramming: Or, how to alter the random oracle on certain inputs.
    \item Extraction: Or, how to learn from the inputs to the random oracle.
    \item Simulation: Or, how to lazy-sample a random oracle.
  \end{enumerate}

  In this gentle introduction to proving security in the QROM, we will show how
  one can recover these capabilities, by surveying the tools developed over the
  past decade, including:

  \begin{enumerate}
    \item The one-way to hiding lemmas
    \item Online-extractability of QROs
    \item The compressed-oracle technique
  \end{enumerate}

  As motivating examples, we will show how one can apply these tools to prove
  the security of popular security paradigms like the Fujisaki--Okamoto
  transformation and the Fiat--Shamir transformations, employed in the recently
  standardized ML-KEM and ML-DSA, respectively.

  We only assume knowledge of basic linear algebra. Hence,
  this tutorial also serves as an introduction to both quantum computing and
  provable security itself, with ample examples and exercises throughout.

\end{abstract}
